06 Workflow · Node-driven workflows

Style "New Design" 16 node + 12 workflow vệ tinh

Trục xương sống chạy qua 16 node với 3 gate duyệt và điểm explode. Mỗi node có owner, deliverable, custom button và automation sinh WIT con. Các workflow vệ tinh (NPL, Pattern, Sample, QC, Factory…) xử lý chi tiết từng nhánh.

Style · New Design

16 node · template chính
1
Brief & Ý tưởngDesigner
Nhận brief từ Product Brief (Calvin đã duyệt). Inherit category, segment, price range. Research trend.
2
Thiết kế phác thảoDesigner
Flat sketch ≥3 phương án, color direction, suggest material.
Gửi Diễm Chi duyệt phác thảo
3
Thiết kế chi tiếtDesigner
Detail front/back/side, confirm color palette, size run, material chính. On-complete: lock sketch phác thảo.
4
Kiểm tra NPLPurchasing
Check tồn NPL, đối chiếu BOM. Gate: chỉ qua khi NPL Check = Hoàn tất & Đầy đủ.
⚡ A_ST1 → tạo NPL Check
⎇ Thiếu → tạo NPL Development hoặc Material PO
5
Làm rập mẫu gốcTechnical2–3 ngày
Vẽ rập base size, tính định mức, soạn bảng thông số.
⚡ A_ST2 → tạo Pattern Making (rập gốc)
6
May mẫu gốcSample Room3–5 ngày
Chuẩn bị NPL, cắt, may, hoàn thiện, chụp ảnh.
⚡ A_ST3 → tạo Sample Order (mẫu gốc)
7
Duyệt mẫu gốcGate 1 · Kỹ thuậtChị Diễm Chi
Fitting / treo mannequin, đo kiểm, đánh giá. Escalate Calvin nếu > 3 vòng.
⚡ A_ST4 → tạo Sample Review (mẫu gốc)
Đạt → N8Sửa → loop N5Hủy sản phẩm
8
Thử mẫu nội bộPP + Merchandising + Design
Team rộng đánh giá thương mại: bán được không? So competitor, confirm target qty.
9
Duyệt nội bộGate 2 · Thương mạiAnh Calvin
Go/no-go thương mại — khác Gate 1 (kỹ thuật).
⚡ A_ST5 → tạo Sample Review (nội bộ)
Chọn mẫu → N10On-hold (park)Hủy sản phẩm
10
Nhảy rập size setTechnical1–2 ngày
Nhảy rập base → full size run, verify grading rule (vd +2cm/size).
11
May size setSample Room5–7 ngày
May đủ size run (1 cái/size), kiểm tra từng size.
⚡ A_ST6 → tạo Sample Order (size set)
12
Duyệt size setGate 3 · SizingDiễm Chi + Technical
Focus: grading có chính xác qua các size? Mọi điểm đo phải Pass.
⚡ A_ST7 → tạo Sample Review (size set)
Đạt → N13Sửa → loop N10Hủy
13
Ban hành Tài liệu KT sản xuấtTechnical
Compile spec sheet final + construction guide + BOM → Diễm Chi duyệt → Lock toàn bộ field thiết kế.
⚡ A_ST8 → tạo Tech Doc
14
Tạo mã Product◆ Explode · Style → SKUProduction
Confirm color/size final → generate SKU matrix → sinh barcode → đẩy KiotViet. SKU tồn tại trước sản xuất (pre-order).
⚡ A_ST9 → Product Registration · A_PR1 → SKU Master per color×size
15
Yêu cầu sản xuấtProduction Planning
Xác định sản lượng final, breakdown color × size, chọn Factory. On-complete: Style → "Đang sản xuất".
⚡ A_ST10 → tạo Production Request
16
Closed — Sẵn sàng bánAuto
Auto-complete khi Production Order hoàn tất + Inbound Lot nhập kho.
